# Ravenloft Music

Синхронизированный музыкальный плеер для Owlbear Rodeo под кампанию
«Проклятие Страда». Только официальный `@owlbear-rodeo/sdk`, никакого своего
сервера — это статичные файлы, которые нужно один раз где-то разместить.

## Что изменилось в версии 2.0

- **Звук играет в фоновой странице** (`background.html`), которую Owlbear
  держит загруженной всю сессию. Раньше звук жил в окне плеера — и умирал,
  как только игрок кликал по карте и окно закрывалось. Теперь окно — просто
  пульт, его можно закрывать.
- **В манифесте запрошено разрешение `autoplay`.** Без него браузер вообще не
  даёт iframe расширения стартовать звук без клика внутри самого окна — это
  и было главной причиной, почему у игроков молчала музыка.
- Если браузер всё же не пускает звук в фон, плеер честно пишет об этом
  внизу окна и играет сам, пока окно открыто (запасной режим).
- Опоздавший игрок больше не «промахивается» за конец трека: позиция
  считается уже после загрузки метаданных, незацикленные треки, которые
  всем уже отыграли, не запускаются, а у мастера кнопка сама возвращается в
  «▶», когда незацикленный трек закончился.
- Одноразовые звуки (саундпад) тоже играют в фоне — у всех, включая мастера.
- `app.js?v=2` в HTML — чтобы Render и браузеры не отдавали старый кеш.

## Файлы

| Файл | Что делает |
| --- | --- |
| `manifest.json` | описание расширения: попап, фон, разрешение autoplay |
| `background.html` / `background.js` | невидимая страница, где живёт звук |
| `index.html` / `app.js` | окно плеера: плейлист, кнопки мастера, редактирование |
| `audio-engine.js` | общий движок воспроизведения (используют и фон, и попап) |
| `library.js` | константы, слияние встроенного плейлиста с правками мастера |
| `data.js` | встроенный плейлист (16 папок, 50 стримов) |

## Как это работает

- **Мастер** (роль GM) видит кнопки play/pause, ползунки и значок ✎ (режим
  редактирования: добавить/скрыть/переименовать треки и папки, всё
  хранится в `room metadata` Owlbear и сразу видно всем). **Игроки** видят
  текущее состояние и свою личную громкость.
- Состояние (что играет, с какого момента, громкость) — в `room metadata`;
  фоновые страницы всех участников читают его и синхронизируются. Игрок,
  зашедший посреди сессии, услышит то же самое с той же позиции.
- Саундпад — `broadcast` на всех, ничего не сохраняется.
- Громкость каждого трека всегда клэмпится в [0, 1] перед `audio.volume`.
- Ссылки Dropbox `dl=0` автоматически переводятся в `raw=1` (прямой файл).

## Размещение

Нужен публичный HTTPS-адрес, по которому доступен `manifest.json`.

**Render (Static Site):** New → Static Site → подключить репозиторий,
Build Command пустой, Publish Directory `.` (корень). Адрес будет вида
`https://<имя>.onrender.com`, манифест — `https://<имя>.onrender.com/manifest.json`.

**GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
Манифест — `https://<логин>.github.io/<репозиторий>/manifest.json`.

Важно: ссылка вида `https://github.com/<логин>/<репозиторий>/manifest.json`
**не** работает — это страница GitHub, а не файл. В Owlbear нужно вставлять
адрес с Render или GitHub Pages.

## Установка в Owlbear Rodeo

1. Extensions → Install extension → вставить URL `manifest.json`.
2. **Если расширение уже было установлено раньше — удали его и добавь
   заново**: Owlbear читает манифест при установке, а в новой версии
   добавились фоновая страница и разрешение autoplay.
3. Игрокам ничего ставить не нужно, расширение появится у них само.

## Если у кого-то нет звука

1. Кликнуть в любом месте комнаты Owlbear или открыть плеер и нажать
   «Включить звук». На значке расширения при блокировке появляется 🔇,
   Owlbear показывает подсказку.
2. Если внизу окна плеера появилась оранжевая надпись про запасной режим —
   браузер не пускает звук в фон. В Chrome/Edge: замок слева от адреса →
   Настройки сайта → Звук → Разрешить, затем обновить страницу. Ещё
   надёжнее — установить Owlbear как приложение (PWA), тогда ограничения
   автозапуска снимаются полностью.
3. iPhone/iPad: Safari не даёт запускать звук без прямого касания каждого
   элемента; там плеер работает только как пульт, звука не будет.
4. Всё остальное — F12 → Console, строки с префиксом `[Ravenloft Music]`.
